# Instrucciones para el agente — Analítica del aprendizaje UCB

## Habilidades y Comandos Rápidos

| Comando / Habilidad | Cuándo usarla |
|---|---|
| `/estilo-docente` o `/redactar` | Aplica el Skill de Estilo Editorial Docente. |
| `AGENTES/ucb-procesar-datos/SKILL.md` | El docente pide **depurar, limpiar, anonimizar o procesar** su base integrada; o menciona la Etapa 2 / PROCESAR. |

## Reglas del espacio de trabajo
- Los archivos originales son de **solo lectura**. Todo ocurre en una carpeta `-REV`.
- **No inventes datos.** Si algo no se resuelve, va al informe de incidencias.
- No escribas datos de estudiantes en archivos de código.
