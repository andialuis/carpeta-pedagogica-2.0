# Instrucciones para el agente — Analítica del aprendizaje UCB

## Habilidades y Comandos Rápidos

| Comando / Habilidad | Cuándo usarla |
|---|---|
| `/estilo-docente` o `/redactar` | Aplica el Skill de Estilo Editorial Docente. |
| `AGENTES/ucb-analizar-datos/SKILL.md` | El docente pide **analizar, cruzar variables, contrastar hipótesis o encontrar perfiles y grupos de riesgo** en su base depurada; o menciona la Etapa 3 / ANALIZAR. |

## Reglas del espacio de trabajo
- La `BASE_DATOS_DEPURADA.xlsx` es de **solo lectura**. El análisis no altera la base de entrada.
- Respeta obligatoriamente las **dos pausas**: (1) Primera pausa para recoger la hipótesis docente, (2) Segunda pausa para presentar y aprobar el plan de 5 tablas.
- **No inventes datos.** Todo hallazgo se contrasta estadísticamente con ajuste por comparaciones múltiples.
